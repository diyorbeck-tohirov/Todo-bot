# Todo bot (Telegram)

Vazifalarni yozib borish uchun Telegram boti (Python, aiogram 3). Interfeys o'zbek tilida.

## Imkoniyatlar
- Vazifa qo'shish, ro'yxatni ko'rish, bajarildi deb belgilash yoki o'chirish
- Bajarilgan vazifalarni ko'rish va tozalash
- Xatolar bot.log ga yoziladi, bot to'xtab qolmaydi

## O'rnatish
1. pip install -r requirements.txt
2. .env.example nusxasini .env ga o'zgartirib, ichiga BotFather'dan olingan tokenni yozing
3. python bot.py

## Muhim
.env fayli GitHub'ga yuklanmaydi. Tokenni hech kimga bermang.
